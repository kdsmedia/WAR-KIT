4. PERINGATAN / ERROR UMUM YANG MUNGKIN MUNCUL

    - "Target API level is not latest" — targetSdk sudah 37 (terbaru), OK.
    - "No active credential" — pastikan App Signing (Play App Signing) aktif.
    - "Privacy Policy URL invalid" — pastikan URL mengarah ke halaman web.
    - "Icon transparency" — pastikan icon 512x512 tidak ada alpha transparan di
      area luar (Play menolak icon dengan transparan). Re-generate bila perlu.
    - "Screenshot aspect ratio" — gunakan 16:9 atau 9:16; sudah sesuai.

Sebelum production, dianjurkan:

    2. Tambahkan tester (email).
